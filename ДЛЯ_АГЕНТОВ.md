# РУКОВОДСТВО ДЛЯ AI-АГЕНТОВ: АДМИНИСТРАТИВНАЯ ПАНЕЛЬ (IJARAUZ ADMIN PANEL VITE)

> **Назначение документа:** Справочник по архитектуре интерфейса, системе ролей и прав, компонентам, маршрутизации, управлению состоянием и правилам разработки панели управления **ijarauz_admin_panel**.

---

## 1. СТЕК ТЕХНОЛОГИЙ И АРХИТЕКТУРА

- **Сборщик и среда:** Vite 8 + React 19 + TypeScript.
- **Маршрутизация:** React Router v6 (`src/routes.tsx`, `src/App.tsx`).
- **Сетевой слой и серверный стейт:** TanStack React Query v5 + Axios с интерцептором токенов.
- **Клиентский стейт:** Zustand (`src/store/authStore.ts`).
- **Компоненты и стилизация:** TailwindCSS + Lucide Icons + кастомные UI-примитивы (`src/components/ui/`).
- **Интернационализация:** `i18next` (Русский / Узбекский / Английский).

## 3. СИСТЕМА РОЛЕЙ И ДОСТУПА

1. **`SUPER_ADMIN`**:
   - Полный доступ ко всем модулям, включая добавление сотрудников (`/settings/staff`), настройки внешнего вида (`/settings/appearance`) и системные дампы.
2. **`ADMIN`**:
   - Доступ к модерации, пользователям, финансовой и поисковой аналитике, промокодам, вебхукам.
3. **`MODERATOR`**:
   - Доступ к списку объявлений, Канбан-доске, жалобам и просмотру профилей пользователей.
4. **`SUPPORT`**:
   - Read-only доступ для консультации пользователей и решения проблем.

## 4. КРИТИЧЕСКИЕ ПРАВИЛА РАЗРАБОТКИ ДЛЯ АГЕНТА

1. **Строгая валидация `VITE_API_URL` (Build-time + Runtime):**
   - На этапе сборки [`vite.config.ts`](file:///c:/Users/vosil/Desktop/ijarauz_project/ijarauz_admin_panel/vite.config.ts) проверяет наличие `VITE_API_URL` в production-режиме и прерывает сборку с ошибкой, если переменная не задана.
   - В рантайме `src/lib/axios.ts` выбрасывает исключение при попытке вызовов без заданного URL.
   - **Чеклист обязательных Environment Variables для деплоя на Vercel (Админка):**
     - `VITE_API_URL` — базовый URL бэкенда (например `https://api.ijarauz.uz` или Railway public URL, БЕЗ слеша на конце).

### Чеклист обязательных переменных окружения (Vercel / Railway)
| Сервис | Переменная | Обязательность | Описание |
| :--- | :--- | :--- | :--- |
| **Vercel (Админка / admin_panel)** | `VITE_API_URL` | **ОБЯЗАТЕЛЬНО** | URL REST API бэкенда Fastify |
| **Vercel (Сайт / ijarauz)** | `NEXT_PUBLIC_API_URL` | **ОБЯЗАТЕЛЬНО** | URL REST API бэкенда Fastify |
| **Railway (Бэкенд / api)** | `DATABASE_URL` | **ОБЯЗАТЕЛЬНО** | Строка подключения к PostgreSQL |
| **Railway (Бэкенд / api)** | `REDIS_URL` | **ОБЯЗАТЕЛЬНО** | Строка подключения к Redis |
| **Railway (Бэкенд / api)** | `JWT_SECRET` | **ОБЯЗАТЕЛЬНО** | Случайный ключ (min 32 символа, `openssl rand -hex 32`) |
| **Railway (Бэкенд / api)** | `REFRESH_SECRET` | **ОБЯЗАТЕЛЬНО** | Случайный ключ (min 32 символа, `openssl rand -hex 32`) |
| **Railway (Бэкенд / api)** | `CORS_ORIGINS` | **ОБЯЗАТЕЛЬНО** | Разрешенные домены через запятую (например `https://ijarauz.uz,https://admin.ijarauz.uz`) |
2. **Type-Only Imports:**
   - При включённой опции `verbatimModuleSyntax` в TypeScript, все импорты интерфейсов и типов **ОБЯЗАНЫ** использовать синтаксис `import type { ... }`.
3. **Оптимистичные обновления и инвалидация кэша:**
   - Все мутации модерации, верификации и блокировок должны сопровождаться `queryClient.invalidateQueries` для актуализации данных без перезагрузки страницы.
4. **Конфиденциальность и видимость фичей:**
   - Функции Fraud Score, дубликаты, финансовые отчеты и системное здоровье доступны **исключительно** авторизованным сотрудникам в панели управления.

## 5. СБОРКА И ПРОВЕРКА

Перед коммитом агент **ОБЯЗАН** выполнить сборку:
```bash
pnpm build
```
Команда запускает `tsc -b` (проверка типов TypeScript) и `vite build` (генерация продакшн-бандла). Ошибок компиляции быть не должно (`exit code: 0`).
