# AVERON Admin — заметки для разработчиков

Панель управления AVERON — отдельное приложение Vite, React и TypeScript.
Маршруты, доступные страницы и guards определяются текущим React Router и
проверяются в `src/routes.tsx`; не добавляйте команды или ссылки на незарегистрированные
страницы.

## Правила изменений

- Для экранов используйте commerce API и типизированные контракты из `src/lib`.
- Финансовые и заказные показатели должны поступать из Backend. При ошибке или
  отсутствии ответа показывайте локализованное состояние «нет данных», а не
  искусственные нули.
- Состояние интеграции показывайте по capabilities/diagnostics Backend; не
  обозначайте провайдера доступным только потому, что существует экран настроек.
- Промокоды должны отражать серверные ограничения AVERON; не создавайте параллельную
  систему скидок.
- Проверяйте RU/UZ/EN для новых административных строк.

## Проверки

Из каталога `AVERON_admin_panel`:

```sh
pnpm test
pnpm lint
pnpm build
```

См. `README.md` для актуального описания приложения.
